## 1. Назначение приложения
Приложение предназначено для расчета и визуализации динамических характеристик фононов в кубических кристаллах:
- Фазовая скорость
- Групповая скорость
- Изоэнергетическая поверхность
- Гауссова кривизна поверхности
- Коэффициент уссиления

Также реализован алгоритм поиска и визулизации каустик фононов

## 2. Подготовка к работе
### Требование к системе
Необходимые установленные библиотеки:
* Python (3.12)
* Matplotlib (3.10)
* Sympy (1.14)
* Numpy (2.4.6)
* Mplcursors (0.7.1)

Скачать приложение можно путем скачивания архива с приложением, либо клонированием репозитория на ваш ПК.

## 3. Работа пользователя

Для запуска приложения необходумо запустить исполняемый файл main.py.

После запуска откроется окно приложения в котором будет отражаться вкладка выбора элемента. На данной вкладке вам предстоит выбрать кристалл из выпадающего списка, либо ввести собсвенное имя кристалла, три модуля упругости и плотность.

### Ограничения ввода
* В наименовании запрещено использовать символы: /, :, ", <, >, |, ?, *;
* Наименование не должно быть пустым;
* При записи десятичной дроби обязательно использвать точку;
* Учитывать размерность модулей упругости (10^12 дин/см^2) и плотности (г/см^3)

После вводка параметра кристалла, расчет характеристик и их визуализация будет запущена путем нажатия на кнопку "Рассчитать характеристики". По завершении расчетов будут созданы вкладки с визуализацией исследуемыххарактеристик:
* Фазовая скорость
* Изоэнергетическая поверхность (для плоскости грани куба и диагональной плоскости куба)
* Изоэнергетическая поверхность трехмерная
* Групповая скорость в плоскости грани куба
* Групповая скорость в диагональной плоскости куба
* Картины каустик для отдельных дисперсионных ветвей
* Общая картина каустики

Для работы с графиками внизу каждой вкладки присутствует панель управления,с помощью которой можно перемещаться по графику, изменять его масштаб, а так имеется возможность сохранить график в разных формататх.

В приложении предусмотрена возможность сохранения вычисленных характеристик в формате csv-файла, для это предусмотрено отслеживание статуса кристалла на главноой вкладке в виде подписей у наименования:
* saved - означает наличие csv-файла из которго могут быть загружены и визуализированы характеристики кристалла;
* calc-d - означает наличие рассчитанных, но не сохраненных характеристик

Для визуализации кристалла со статусом "saved", необходимо выбрать его из выпадающего списка и нажать кнопку "Загрузить характеристики", после чего будут созданы вкладки с визуализацией характеристик.

Для сохранения характеристик кристала со статусом "calc-d", необходимо выбрать его из выпадающего списка и нажать кнопку "Сохранить характеристики", после чего будут созданы csv-файлы с характеристиками кристалла и статус кристалла изменится на "saved".

При выходе из приложения осуществяется проверка на наличие несохраненных расчетов, для этого будутвыведены наименования кристаллов для которых не было проведено сохранение, что позволяет пользователю не потерять расчеты.

## 4. Работа с ошибками
При возникновении ошибок в связи с действиями пользователя, приложение выдает соответствующие предупреждения:

### Введены некорректные константы
Убедитесь в правильности введнного наименования и констант кристалла в соответствии с разделом "Огранечения вводв".

### Не найдено вычисленных значений для данного кристала, Выберите кристалл для загрузки значений
Для успешной загрузки вычисленных значений, необходимо выбрать кристалл из выпадающего списка со статусом "saved" либо "calc-d"

### Не получилось сохранить вычисления
Для успешного сохранения вычислений, необходимо выбрать кристалл из выпадающего списка со статусом "calc-d"
